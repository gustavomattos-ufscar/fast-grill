# Fast Grill

Jogo desenvolvido para a disciplina Estruturas de Dados (1001098) — UFSCar, 2026/2.

O jogador é o cozinheiro de uma lanchonete: atende os pedidos em **fila** (FIFO)
e monta cada lanche em uma **pilha** (LIFO), com opção de desfazer o último ingrediente.
